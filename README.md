# ChamferSheet

個人的なツール用CSS。\
良さげなものが見当たらないので適当に作る。\
とりあえず、どこからでも使えるように置いておく。

互換性等、まったく気にしてないので悪しからず。

- バージョン固定: https://cdn.jsdelivr.net/gh/S-Remi/ChamferSheet@v0.1.0/chamfer.min.css
- 最新バージョン: https://s-remi.github.io/ChamferSheet/chamfer.min.css

書体（IBM Plex）の `@import` を含まない版も置いてある。オフライン前提のアプリや、
同じ書体を自分で `<link>` して読んでいる場合はこちら。

- バージョン固定: https://cdn.jsdelivr.net/gh/S-Remi/ChamferSheet@v0.1.0/chamfer.nofont.min.css
- 最新バージョン: https://s-remi.github.io/ChamferSheet/chamfer.nofont.min.css
